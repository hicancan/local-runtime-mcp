# v18.4.0 — Full-Stack Reliability, Latency & Storage Overhaul

## Highlights

### Native Windows Desktop Worker (`native/computer-windows` + `internal/computer`)
- **Fixed UIA semantic lock deadlock**: guarded `SEMANTIC_ACTIVE` with an RAII `Drop` guard so early error returns never leave `desktop.state` / `desktop.wait` permanently locked.
- **0% idle CPU overlay thread**: replaced the 125 Hz `PeekMessageW` polling loop with event-driven `GetMessageW` + `PostThreadMessageW` wakeups and honored custom control pill labels.
- **Faster screenshots & downscaling**: added `max_width` / `max_height` proportional resizing to `desktop.state`, stripped opaque alpha (`Rgba8` → `Rgb8`, −25% raw pixels), and switched PNG encoding to fast Sub-filtered compression.
- **Content-hashed worker cache & bounded FIFO stores**: cached the embedded Windows worker binary by SHA-256 hash to avoid repeated extraction and AV rescans; replaced hard map clears with FIFO eviction for state and live UIA element tables; cached `IUIAutomationCacheRequest` and pre-filtered before querying patterns.

### Stateful JavaScript Runtime (`internal/jsrt`)
- **Complete closure sync & hoisting**: wrapped top-level execution in `try { ... } finally { ... }` so mutable top-level `let`/`var`/`class`/`function` bindings, hoisted functions declared after early `return`, and nested block `var` declarations persist reliably across turns.
- **Goja AST & interrupt hardening**: extended zero-arg `NewExpression` AST span repair to arrow-function expression bodies (`() => new Date()`); `wait(terminate: true)` now interrupts synchronous infinite loops cleanly via `vm.Interrupt` / `ClearInterrupt`; panic recovery and promise cancellation no longer strand active cell counters; session teardown cancels pending timers.
- **Web globals & SDK contract accuracy**: fixed `URL` userinfo and non-hierarchical schemes (`mailto:`, `data:`), `new URLSearchParams(existing)`, Latin-1 `atob`/`btoa`, cached `time.LoadLocation` lookups, honest `emitImage` return status past cap, strict `proc.run` shell validation, and 100% alignment across `help()`, `run` schema description, and runtime bindings.

### Native Browser CDP Engine (`internal/browser`)
- **Zero-I/O hot path & clean error classification**: cached `DevToolsActivePort` discovery with a 2 s TTL and added a zero-disk fast path for already-connected CDP clients; transient dial failures and context cancellations mark instances `offline` instead of permanently `rejected`.
- **AX snapshot accuracy & token savings**: replaced multiset diffing with order-aware Myers $O(ND)$ line diffing, pruned `InlineTextBox` and redundant child `StaticText` nodes, fixed monotonic snapshot sequence IDs past 8 snapshots, and parallelized OOPIF `Accessibility.getFullAXTree` calls.
- **CDP concurrency & memory safety**: fixed a concurrent write race in `sendAllowDialog`, zero-copy WebSocket frame reads, browser-root target detachment cleanup, GC-safe ring buffers, bounded trace event retention, safe heap-snapshot sink unregistration before flush, and detached `Runtime.releaseObject` cleanup contexts.

### Audit SQLite Store, Filesystem, Process & Lifecycle (`internal/audit`, `internal/filesystem`, `internal/process`, `internal/mcpserver`, `internal/transport`, `internal/connection`, `internal/runtimehost`, `internal/ui`, `internal/cli`)
- **Compact SQLite FTS5 & blob GC**: migrated from trigger-driven external-content FTS5 (3 passes per tool call, full 48 KB JSON indexing) to a standalone bounded-excerpt FTS5 index written once on completion inside a single transaction, with `auto_vacuum=INCREMENTAL`, `journal_size_limit`, WAL checkpointing on close, automatic retention pruning, and orphan image blob garbage collection.
- **Session lifecycle fidelity**: `session(action="done")` now clears active task routing and guards `FinishTool` so completed sessions never resurrect; `run` accepts an optional explicit `session_id`; remote `wait` enforces session ownership; Studio UI no longer renders a green active dot on finished sessions.
- **Process & filesystem speedups**: Windows executable lookup now resolves MSIX App Execution Aliases (`wt.exe`, `winget.exe`, etc.); replaced quadratic `streamBuffer` shifts with an $O(1)$ circular ring buffer; added context cancellation, `max_depth` `filepath.SkipDir`, extension MIME fast path, single-buffer literal search fast path, exact truncation detection, and minified-line caps to `internal/filesystem`.
- **Daemon & CLI polish**: fixed local-mode `localSrv` shadowing panic, invoked custom shutdown hooks on `HTTPServer.Close` so hijacked `/mcp/attach` streams close immediately, reclaimed disconnected stdio session VMs/tabs, pooled loopback HTTP transports, closed `machineTools` on shutdown, released locks before audit writes in `IngressManager`, and added `--version` / `-v` / `--help` / `-h` CLI aliases.
