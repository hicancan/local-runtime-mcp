# v18.4.3 — Audit Timeline Lifecycle Cleanup & Live Studio Sync

## Highlights

- **First-class audit timeline deletion**: added atomic `Store.Delete` and `DeleteSession` across the embedded SQLite WAL + FTS5 audit store, purging matching sessions, events, trigram FTS5 index entries, in-flight caches, and unreferenced image blobs in one pass while protecting the built-in `lrmcp-daemon` / `system:daemon` timeline.
- **Full-stack control plane**: exposed `POST /admin/audit/delete`, CSRF-protected `POST /ui/api/audit/delete`, hover-reveal delete controls on client folders and session rows in the local Activity Studio (`/ui`), and `lrmcp audit delete` (working seamlessly both against a running daemon and offline directly on `lrmcp-audit.db`, with `--vacuum` compaction).
- **Real-time SSE refresh sync**: deletion operations broadcast a lightweight `refresh` SSE packet so open Studio tabs immediately drop removed timelines and update database statistics without manual reload.
