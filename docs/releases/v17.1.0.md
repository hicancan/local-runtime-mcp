# v17.1.0 — Per-Client `--agent` Attribution for Local `stdio` Proxies

`v17.1.0` adds optional `--agent NAME` (and `LOCAL_RUNTIME_MCP_AGENT_ID` environment fallback) to `lrmcp serve --transport stdio`, forwarded over `X-LRMCP-Agent` during `/mcp/attach` so multiple local clients sharing one client binary name (such as separate IDE profiles or WSL vs Windows clients) appear under clear, distinct labels in `lrmcp ui` and `lrmcp audit`.
