# v18.2.1 — Exact Parenthesized Expression & Initializer Boundary Handling in AST Rewriter

`v18.2.1` fixes a subtle boundary edge case in the Goja ECMAScript AST REPL rewriter introduced in `v18.2.0`:

- **Exact Parenthesized Expression Spans (`internal/jsrt/rewrite.go`)**:
  - Goja's AST omits wrapper nodes for parenthesized expressions (`({ ... })`, `((a + b))`, `(a + b) * 2`, `2 * (a + b)`, `const x = (1 + 2)`), so `Idx0()`/`Idx1()` sit inside outer `(` and `)`.
  - Added `skipWSAndComments` and `statementEndAfter` to expand declaration ends past closing `)` / `;` and preserve all outer/side parentheses on the final auto-returned `ExpressionStatement`.
- **Expanded Regression Coverage (`internal/jsrt/runtime_test.go`)**:
  - Verified parenthesized object literals, double-parenthesized expressions, left/right/both-side parenthesized binary expressions, parenthesized `const` initializers, trailing comments, and function declarations followed by empty statements.
