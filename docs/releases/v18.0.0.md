# v18.0.0 — Unified Stateful JS Orchestration, Browser-Level CDP & 4-Primitive MCP Surface

`v18.0.0` completes a full architectural forward evolution of `lrmcp`, collapsing the entire machine + browser + DevTools + desktop surface into **4 orthogonal MCP primitives** backed by a persistent concurrent JavaScript runtime and native browser-level CDP.

## Breaking Changes & Forward Evolution

- **4-Primitive MCP Surface (replaces 24 flat tools)**:
  - `run(title, code, done_title?, yield_ms?, max_output_bytes?)`: Stateful per-session Goja JS runtime with true goroutine-backed `Promise.allSettled([...])` concurrency across `proc`, `fs`, `browser`, `desktop`, `img`, `caps`, `emitImage`, `print`, and `sleep`. Top-level variables and helper functions persist across turns. `title` is required and flips to `done_title` automatically on completion.
  - `wait(cell_id, yield_ms?, terminate?)`: Unified async continuation and cancellation for any running cell.
  - `session(action='start'|'update'|'done', title?, message?, status?, session_id?, agent_id?)`: Task thread management and automatic cleanup of temporary browser tabs on `done`.
  - `capability_propose(name, definition, script)`: Propose reusable owner-approved site capabilities.
- **Native Browser-Level CDP Engine (subsumes `chrome-devtools-mcp`)**:
  - Auto-discovers running Edge/Chrome instances via `DevToolsActivePort` (or explicit `browser.cdp_endpoints`) and connects directly from Go over a persistent multiplexed browser-root WebSocket.
  - Supports **browser-process-level `Tracing.start`/`Tracing.stop`** with `IO.read` streaming and Web Vitals / long-task parsing, passive `Network` + `Console`/`Log` ring buffers, `Network.getResponseBody`, `Emulation` (viewport, mobile, CPU/network throttling, media features, geolocation, headers), `CSS` matched/computed styles, streamed V8 `HeapProfiler.takeHeapSnapshot`, `Debugger` logpoints, `Page.startScreencast`, and raw browser-root/tab `cdp.send`.
  - Adds **incremental AX snapshot diffing**, Playwright-style semantic locators (`getByRole`, `getByText`, `getByLabel`, `getByPlaceholder`, `locator`) with auto-wait, truly concurrent `browser.open`, and `markHandoff()` tab lifecycle management.
- **Slimmed Browser Extension (zero `chrome.debugger`)**:
  - Removed `"debugger"` permission and all CDP automation/scheduling code from the MV3 extension (no more extension debugging infobar). The extension now strictly serves Web-to-Local capabilities (`web_bridge`), the toolbar `L` owner grants panel, and optional native Edge/Chrome Tab Group styling (`tabGroups`).
- **Audit & Studio UI Improvements**:
  - Dual-state `title` → `done_title` timeline rows with structured `sub_ops` execution breakdowns, automatic 15-minute idle decay for inactive sessions, persistent connection session binding across stdio/in-memory transports, and one-click CDP browser connect in Studio `/ui`.
- **Cloud CI/CD Removed**:
  - Removed `.github/workflows/ci.yml` and `.github/workflows/release.yml` for streamlined local-first builds.
