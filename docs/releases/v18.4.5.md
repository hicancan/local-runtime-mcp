# v18.4.5 — Modern MOOC Outline Support, OAuth Client Attribution & Faster Clipped Screenshots

## Highlights

- **Modern China University MOOC courseware outline (`icourse.outline`)**: updated [outline.js](../../capabilities/icourse/outline.js) to support MOOC's redesigned `/mooc/learn/<course>/content` layout (`details.course-outline-chapter`, `[data-testid="course-outline-lesson"]`, `[data-testid="course-outline-assessment-link"]`) alongside the legacy `/learn/<course>#/learn/content` layout, while continuing to fail closed on foreign origins, quiz pages, lesson player URLs, and unloaded pages.
- **Real OAuth client attribution**: added `oauth.Server.AuthenticateBearer` returning the registered `client_id` so public OAuth connections are attributed cleanly to their real client identity (e.g. `chatgpt`, `gemini`) in audit logs and Studio UI instead of a generic `oauth` label.
- **Faster clipped & viewport screenshots**: `screenshotTab` now fetches target metadata concurrently off the critical path and skips the redundant `Page.getLayoutMetrics` CDP round-trip when explicit clip bounds are provided.
