# v18.4.9 — Silent Windows Subprocess Spawns (Zero Console Flashes)

## Highlights

- **Zero flashing console windows on Windows**: applied `windows.CREATE_NO_WINDOW` across `proc.run` managed subprocess launches (`internal/process/process_windows.go`) so headless daemon executions of `powershell.exe`, `pwsh.exe`, `cmd.exe`, `git.exe`, `python.exe`, and other CLI tools never allocate or flash transient console/Windows Terminal windows, while keeping `HideWindow` unset so explicit GUI apps and windows still display normally.
- **Complete spawn-site hygiene**: added `windows.CREATE_NO_WINDOW` to `cloudflared` companion launches, local app capability executions, and capability approval `git` commits, and removed the conflicting `DETACHED_PROCESS` flag from detached daemon spawning (`CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW`) so Windows honors `CREATE_NO_WINDOW` per Win32 `CreateProcessW` semantics.
