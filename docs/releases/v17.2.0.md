# v17.2.0 — Per-Client Sidebar Folders and Multi-Task Session Switching

`v17.2.0` upgrades the embedded Activity Studio (`lrmcp ui`) and `agent_report` for multi-task workflows:

- **Collapsible per-client sidebar folders**: Sessions are now grouped under collapsible folders keyed by `agent_id` (e.g., `dots`, `codex-1`, `agy`, `claude-wsl`), showing each task thread beneath its folder with wire badges, live working indicators, pagination (`Show N more`), and `client / task title` breadcrumbs.
- **Per-task session switching**: `agent_report` now supports optional `new_session: true` and `session_id` parameters. Persistent local connections bind subsequent tool calls to the newly opened task session automatically; stateless remote HTTP/Cloudflare callers can also isolate concurrent tasks via the `X-LRMCP-Session` header.
