# v18.3.1 — Fix Zero-Argument `new Foo()` End-Offset in AST REPL Rewriter

`v18.3.1` fixes an upstream Goja AST edge case caught during live verification:

- **Zero-Argument `NewExpression` Boundary (`internal/jsrt/rewrite.go`)**:
  - Goja's `(*ast.NewExpression).Idx1()` checks `ArgumentList != nil` instead of `RightParenthesis > 0`, so zero-argument `new Date()` returned an end offset *before* `()`, causing the AST persistence rewriter to insert between `Date` and `()` and fall back to the unmodified wrapper.
  - Added `trueIdx1(ast.Node)` to propagate `RightParenthesis + 1` accurately across right-edge AST wrappers, and added regression coverage for zero-argument `new Date()`, no-paren `new Date`, parenthesized `(new Date())`, and UTF-8 comments/identifiers.
