# v17.0.0 — Embedded SQLite WAL + FTS5 Audit Engine, Sovereign Activity Studio (`lrmcp ui`), `agent_report`, and Multi-Client Cloud Access

`v17.0.0` completes the observability and sovereign control layer of Local Runtime MCP (`lrmcp` + paired Chromium extension `v17.0.0`): every local, remote, web, and scoped-client tool invocation is captured in a high-performance embedded database with zero external dependencies and streamed live to a minimalist local-only Studio UI.

## What Changed

### 1. Embedded Pure-Go SQLite WAL + FTS5 Activity Store (`internal/audit`)
- Zero-CGO `modernc.org/sqlite` database stored beside `local-runtime-mcp.yaml` as `lrmcp-audit.db` with WAL journaling, trigram FTS5 full-text search (supporting instant CJK and English substring search), and content-addressed image blobs (`lrmcp-blobs/<sha256>`).
- Automatic secret redaction strips token, password, secret, API key, cookie, and `LOCAL_RUNTIME_MCP_*` environment fields before persistence.
- Built-in JSONL export (`lrmcp audit export` / `/ui/api/export`) and real-time Server-Sent Events pub/sub (`lrmcp audit tail` / `/ui/api/stream`).

### 2. Zero-Invasion Full-Ingress Auditing, `agent_report`, and Live Session Kick
- MCP receiving middleware automatically records every `tools/call` across local (`9317`), OpenAI Tunnel, and Cloudflare / public HTTP (`9316`), plus Web bridge (`capabilities.invoke`) and local scoped clients (`/capabilities/invoke`).
- New read-only, zero-side-effect built-in tool **`agent_report`** (`message`, optional `title`, `agent_id`, `status`) lets local or cloud callers post concise narrative milestones directly into the live timeline between collapsed tool-call capsules.
- Live owner kick switch (`POST /admin/sessions/kick` / Studio UI) terminates active MCP sessions and attached `stdio` proxies on demand.

### 3. Local-Only Sovereign Activity & Audit Studio (`lrmcp ui`)
- Embedded directly inside the single `lrmcp` binary via `//go:embed` (zero external CDN requests, strict CSP, light/dark theme, bilingual ZH/EN).
- Strictly mounted on `127.0.0.1:9317/ui` (never exposed on `9316` or tunnels).
- Protected by single-use 60-second bootstrap URLs (`POST /admin/ui/bootstrap` via `lrmcp ui`, or 1-click **Studio / 活动台** button in the `L` extension popup) that exchange into an `HttpOnly; SameSite=Strict` session cookie plus same-origin `X-LRMCP-UI` CSRF checks.
- Pure live observation and sovereign controls: collapsible tool capsules, narrative `agent_report` prose, clickable screenshot/image previews, inline Web MCP proposal code review and approve/reject, live tunnel hot-plug + TTL + Read-Only controls, and emergency desktop stop.

### 4. Multi-Client Cloud Access (`grants.remote.tokens`)
- New `lrmcp setup remote-token --id NAME [--read-only] [--tool NAME]` command creates independent named Bearer tokens on `127.0.0.1:9316/mcp` with optional per-token read-only or allowlist policies.
- Named remote tokens coexist cleanly with `http.auth: oauth` on a single Cloudflare Tunnel while keeping legacy static `http.bearer_token` rejected under OAuth.
- Supports `X-LRMCP-Agent` / `X-Agent-Id` and `X-LRMCP-Session` attribution headers so concurrent cloud workers appear as independent live timelines.

### 5. Streamlined Windows + Linux CI & Release Matrix
- Removed `macos-latest` / `darwin` jobs from GitHub Actions CI and Release workflows so every push and release builds and verifies rapidly on Windows (`amd64`) and Linux (`amd64`, `arm64`).
