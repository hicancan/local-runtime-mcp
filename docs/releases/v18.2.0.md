# v18.2.0 — AST-Powered REPL Rewriter, Web Standard Globals & Unified Documentation

`v18.2.0` hardens the embedded stateful JavaScript runtime and aligns all public documentation and metadata with the v18 unified architecture:

- **ECMAScript AST-Based REPL Rewriter (`internal/jsrt/rewrite.go`)**:
  - Replaced the hand-written 675-line lexical scanner with Goja's native `github.com/dop251/goja/parser` AST rewriter (~170 lines).
  - Supports top-level `let`, `const`, `var`, multi-declarators, nested object/array/default/rest destructuring, `function`, `async function`, and `class` persistence across turns—including re-declaring the same `const` identifier on subsequent turns—while preserving exact bare-expression REPL auto-return.
- **Standard JS / Web Globals Inside `run` (`internal/jsrt/webglobals.go`)**:
  - Added zero-dependency `URL`, `URLSearchParams`, `atob`, `btoa`, `setTimeout`, and `clearTimeout` (bound to active cell cancellation so timers never leak).
- **Capability Schema & Documentation Overhaul**:
  - Updated `capability_propose` and capability envelope descriptions to reflect v18 `browser.status()` / `browser.tabs()` / `tab.snapshot()`.
  - Rewrote `README.md` and `README.zh-CN.md` from the ground up around the v18 unified architecture (4 orthogonal primitives, stateful concurrent JS VM, native browser-level CDP, slim zero-debugger extension, Web/App MCP compilation loop, Studio UI, and hot-plug tunnels).
