# v18.4.1 — Background-Tab CDP Input & Screenshot Root-Cause Fixes

## Highlights

- **Zero-stall background-tab browser actions (5000 ms → <5 ms)**: when dispatching mouse or keyboard input (`click`, `double_click`, `hover`, `drag`, `fill`, `type_text`, `press_key`, `scroll`) to a hidden background tab (`document.hidden === true`), `cdpClient` now scopes `Emulation.setFocusEmulationEnabled(true)` around the action and restores it on exit so Chromium's Blink input handler never hits its 5-second coalesced `mouseMoved` watchdog timeout, while leaving already-visible tabs completely untouched.
- **Non-blocking background-tab screenshots without stealing focus**: when `tab.screenshot()` targets an occluded background tab without an active caller emulation override, `cdpClient` now scopes `Emulation.setDeviceMetricsOverride` (`deviceScaleFactor: 1`) around `Page.captureScreenshot` (with a bounded 20 s capture deadline) so Chromium commits an offscreen compositor frame in ~40 ms instead of hanging indefinitely waiting for tab activation.
- **Accurate locator telemetry labels**: replaced the always-non-empty `loc.Role + ":" + loc.Name` fallback with `formatLocatorTarget(loc)` across `locator.*`, `tab.click`, and `tab.css`, reporting `placeholder=...`, `label=...`, `text=...`, `role:name`, `css`, or `ref` cleanly in `sub_ops` and Studio UI.
- **Evolution backlog**: added [evolution-backlog.md](../evolution-backlog.md) as a clean, active-only root-cause engineering backlog.
