# v18.4.2 — Unified Chromium Background-Tab Capturer Lifecycle

## Highlights

- **Single root-cause fix for all occluded background-tab operations**: replaced per-action `Emulation.setFocusEmulationEnabled` toggling and `Emulation.setDeviceMetricsOverride` screenshot workarounds with Chromium's native `WebContents::IncrementCapturerCount` lifecycle via a lightweight keep-alive `Page.startScreencast` (`16×16`, quality 1, `everyNthFrame: 60`) with zero-allocation frame skipping when user screencast recording is off, automatic 15 s idle release, and immediate release on `tab.markHandoff()`, tab close/detach, or explicit `tab.screencastStart()`.
- **Consistent 60 FPS background automation**: consecutive `fill` → `click` → `screenshot` sequences on hidden background tabs (`active: false`) now complete in ~20–75 ms per operation without switching the active tab, stealing OS focus, distorting HiDPI devicePixelRatio, or hitting Chromium's 1 Hz / 5 s occluded-tab throttles.
